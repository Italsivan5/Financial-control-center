# Financial Control Center 1.2

## מה כלול
האפליקציה כוללת:
- Dashboard עם תובנות ואיכות נתונים
- תזרים: הכנסות, הוצאות, חיסכון, עסקאות שבוצעו ועסקאות צפויות
- שווי נקי: נזילות, השקעות, נדל"ן וחובות
- תיק השקעות מפורט
- Market Lab / Watchlist עם Quality, Growth, Valuation
- פנסיה וקרנות: יתרה, הפקדה, דמי ניהול, מסלול ותחזית
- מטרות וחישוב חיסכון חודשי נדרש
- Financial Time Machine: שמרני / בסיס / אופטימי
- What-If לחיסכון חודשי נוסף
- מנוע תובנות
- בדיקת שלמות הנתונים
- גיבוי וייבוא JSON
- PWA / עבודה offline

## חשוב לפני הכנסת נתונים פיננסיים אמיתיים
הקובץ `index.html` עובד כרגע מקומית ושומר נתונים ב-localStorage של הדפדפן.
זה מצוין לבדיקת המערכת, אבל לא מומלץ כמקום היחיד לשמור בו מידע פיננסי אמיתי לאורך זמן.

השלב הבא לפרודקשן:
1. לפתוח פרויקט Supabase.
2. להריץ את `supabase_schema.sql`.
3. לחבר Authentication.
4. להחליף את שכבת localStorage בקריאה/כתיבה ל-Supabase.
5. להשאיר cache מקומי ל-offline ולסנכרן כשיש אינטרנט.

מבנה הטבלאות כבר תואם למודל באפליקציה, ולכן המעבר הזה אינו דורש להזין מחדש נתונים אם מייבאים את גיבוי ה-JSON.
